# First-party media and sample content

The public CharmShelf source snapshot was prepared on 2026-11-02 from the application's first-party source. The existing `Copyright (c) 2026 Private Shelf Project` notice is retained in the [root MIT license](../LICENSE). This public snapshot's source license does not replace any third-party license.

## Public assets

- Brand icons, splash art, and sample PNG images are original procedural drawings generated by `tool/public_assets/generate_assets.py` for CharmShelf.
- The two sample MP3 files and sample MP4 are newly generated demonstration media from that script, replacing the previous music and brand video. Their legacy filenames are implementation details; the original recordings are not included.
- `tap.mp3`, `success.mp3`, and `error.mp3` are first-party wave-synthesized UI sounds. Their source is `tool/ui_sounds/generate_ui_sounds.py`; no external recording is used. The three retained MP3s were reproduced from the source and matched byte-for-byte in the original provenance check. Re-encoding with different encoders may change the bytes.
- Functional SVG icons are first-party vector source. Sample Markdown contains first-party demonstration text.

These first-party files and their generation scripts are licensed under MIT, as stated in [assets/LICENSE](../assets/LICENSE). Retain the copyright and license notice when redistributing them. Third-party packages used by generation tools retain their own licenses; installing a tool does not transfer its license to generated media.

## Excluded original media

The old Suno music, old brand video, old generated brand/sample raster images, and the unverified `ice_glass_clink.wav` are not the public snapshot's inputs. Earlier permission to bundle those assets in the application is not treated as permission to sublicense them as reusable open-source media. The unknown WAV has no application reference and is not required by the public build.

`assets/licenses/` contains third-party legal text, rather than media governed by the first-party asset license. See [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) for those exceptions. Flutter Material Icons and other dependency-owned resources keep their original notices.

When replacing sample media, update this inventory and keep a reproducible source. Do not assume a new download or generated file has the same permission as an existing asset.
