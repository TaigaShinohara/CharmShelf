# プライバシーポリシー

最終更新日: 2026-10-02（公開前の更新案）

## 1. 基本方針と運営者情報
CharmShelf（以下「本アプリ」）は、データをまず端末上で扱うローカルファースト設計です。本アプリがライブラリデータを開発者運営のサーバーへ自動アップロードすることはありません。

- **運営主体**: Private Shelf Project（CharmShelf 開発チーム）
- **お問い合わせ窓口**: deeple+charmshelfstaff@inkboxmail.com

## 2. 収集・保存する情報
本アプリは、機能提供のために以下の情報を主にお客様の端末内で扱います。共有・書き出し・サポート送付を選ぶと、選択したデータが指定した相手やサービスへ渡ります。これらの情報が開発者のサーバー等へ自動送信されることはありません。
- **メディア・ファイルデータ**: ユーザーが本アプリに取り込んだファイル、または参照を許可したファイル（写真、動画、音声、PDF、テキスト等）
- **ライブラリ管理情報**: フォルダ構成、チャーム、別名、メモ、お気に入り、表示順序、非表示・アーカイブ状態
- **取り込み元と移行情報（Android）**: OSで選択・許可した場所からファイル名、保存場所、種類、サイズ、更新日時、識別情報を読み取り、取り込み候補を表示します。新しい恒久索引や元ファイル上の整理情報は作成しません。登録した取り込み元の読み取り権限は、再利用のため端末内に保持します。旧版で保存した候補・チャーム・カタログ名・お気に入り、および外部参照の移行記録は、引継ぎと復旧のため端末内に保持します。元ファイルへ書き込みません。
- **アプリ設定・キャッシュ**: 表示設定、サムネイル画像、パフォーマンス向上のためのキャッシュ
- **ローカルクラッシュログ**: 不具合調査のため端末内にのみ一時生成されるエラーログ

## 3. 外部送信、バックアップ、トラッキング
- **第三者トラッキングの不実施**: 本アプリは、広告配信SDKや行動追跡アナリティクスSDK（Google Analytics、Firebase、Facebook SDK等）を一切組み込んでおらず、ユーザーの行動履歴や広告識別子（IDFA/AAID）を取得・追跡することはありません。
- **外部送信の不実施**: ユーザーの明示的な操作（サポートへのメール送信、共有機能の利用など）を除き、個人データやライブラリデータが外部サーバーへ自動送信されることはありません。
- **支援購入とストア通信**: 商品情報取得・購入・完了処理ではOSのストアと情報をやり取りします。取引の識別情報・状態・完了処理に必要な情報を扱い、未完了取引の確認・完了処理のため、起動時や画面への復帰時にもストアと通信します。
- **自動バックアップからの除外**: アプリ管理用の私有領域（管理データ、操作復旧情報、ローカルクラッシュログを含む）は、自動クラウドバックアップおよび端末間転送の対象から除外するよう設定しています。ただし、共有・書き出し・サポート送信したデータ、Androidの公開フォルダ、外部参照元、外部サービス側のデータは除外対象外です。

## 4. 端末権限の利用目的
本アプリは、以下の権限を正当な機能提供のためにのみ使用します。
- **ストレージ・ファイルアクセス権限（Android: OSのファイル選択・Storage Access Framework、および旧OS向け互換ストレージ権限 / iOS: ドキュメントアクセス）**:
  ユーザーが許可したファイルの選択、参照、コピー、整理、表示、書き出し、復元のために使用します。
- **Androidのファイル選択**:
  OSの個別ファイル選択とフォルダ選択を使用し、ユーザーが許可した範囲を読み取ります。すべてのファイルへのアクセスは要求しません。取り込み元の登録解除は元ファイルを削除しません。
- **写真ライブラリ権限**:
  ユーザーが選択した写真・動画を取り込み、または書き出すために使用します。現行画面にカメラ撮影機能はありません。
- **生体認証（Face ID / Touch ID / 指紋認証等）**:
  アプリロックの解除および再認証に使用します。生体情報そのものは端末のセキュア領域（OS）で処理され、本アプリが取得・保存することはありません。
- **通知権限**:
  ファイル取り込みの進捗・完了を表示するために使用します。許可しなくても取り込み機能は利用できます。
- **ネットワーク接続状態の確認**:
  外部ヘルプページや法規ページの表示確認、およびオフライン動作の制御のために参照します。支援購入の取引確認・完了処理ではOSのストアとの通信も行います。

## 5. セキュリティと機能の技術的限界（免責事項）
- **非表示・アーカイブ機能**: アプリ内での表示を整理・制限するものであり、ファイル自体を不可逆的に暗号化・秘匿するものではありません。
- **アプリロック機能**: 本アプリ画面へのアクセスを制限するものであり、端末自体の不正操作やOSレベルでのファイルアクセスを完全に防ぐものではありません。
- **データ保全**: 管理情報は端末内に自動保存されます。設定の「ライブラリのバックアップ」から、アプリ内のファイルと、チャーム・別名・メモ・お気に入り・履歴などの整理情報をまとめて保存・復元できます。復元は専用フォルダへ追加し、同じ識別情報を持つ既存データを上書きしません。旧外部参照は先にアプリ内へコピーしてください。バックアップには非表示・アーカイブ・ごみ箱の内容も含まれます。バックアップファイルは暗号化されていません。保存先を選ぶ前に内容と保存場所を確認し、安全な場所で保管してください。アプリロックのパスコード・生体認証設定・OSのアクセス権限は含まれません。チャーム定義だけの書き出しは、ライブラリ全体のバックアップではありません。重要な元ファイルは別途アプリ外にも保管してください。
- **免責**: 端末の紛失・故障、OSの不具合、ユーザーによる誤操作、パスワードの紛失等によるデータの消失や漏洩について、開発者は一切の責任を負いかねます。重要な元ファイルはアプリ外にも保管し、保存先で開けることを確認してください。

## 6. データの共有・外部提供
ユーザーが以下の操作を行った場合、データはユーザーが選択した提供先へ渡り、その後の取り扱いは提供先サービスの規約・プライバシーポリシーに従います。
- 共有シート（Share）を通じた他アプリ・SNS・クラウドストレージへのデータ送信
- 選択したファイルの外部ストレージ・クラウドサービスへの書き出し
- ライブラリの手動バックアップ（アプリ内コピー、整理情報、非表示・アーカイブ・ごみ箱、閲覧履歴を含みます。保存先がクラウドサービスの場合、そのサービスにも渡ります）
- チャーム定義JSONの書き出し（カタログへの割当・お気に入り・メモを含むライブラリ全体のバックアップではありません）
- Androidのカタログ書き出しに付随する整理情報の書き出し（チャーム割当・メモ・名前・保存場所の情報などを含みます。同じ保存先を他のアプリやサービスと共有すると、これらの情報も共有の対象になります）
- サポート対応のためにユーザー自身がメール等で開発者へ送付した情報

## 7. データの保持期間と削除
- アプリ管理用コピーは、アプリ内の削除操作で確認画面に示された対象を削除します。
- 旧外部参照の解除では登録と関連情報を削除し、元ファイルは残します。移行前の管理情報の退避と途中コピーは復旧のためアプリ内に保持します。
- 端末ファイルの索引・整理情報は、権限を取り消しても端末内に保持します。「全データ削除」またはアンインストールで削除されます。検索対象から除外した場所の整理情報は、後から再利用できるよう保持します。これらの操作で参照元の実ファイルは削除しません。
- Androidの公開フォルダ、外部参照元、共有先、書き出し先は、アプリのアンインストール後も残る場合があります。
- AndroidとiOSのアプリ私有領域は、アンインストール時に通常削除されます。アプリ内に保存した管理情報も削除対象です。チャームやカタログ設定が元ファイルから自動的に復元されるわけではありません。

## 8. 未成年者のプライバシー保護（COPPA / GDPR対応）
本アプリは全年齢を対象としており、13歳未満の児童を含む未成年者からも意図的に個人情報を収集することはありません。未成年者が利用する場合は、必要に応じて保護者（法定代理人）の同意を得た上でご利用ください。

## 9. プライバシーポリシーの改定
法令の改正やアプリの機能追加等に伴い、本ポリシーを予告なく改定することがあります。改定後のポリシーは本アプリ内および公開ページに掲示された時点で効力を生じるものとします。
