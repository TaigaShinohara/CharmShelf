# CharmShelf Usage Notes

## Four ways to collect files

1. Turn photos into a photo book
2. Turn music into an album
3. Turn illustrations into an art collection
4. Turn text into a book

You can add charms, an alias, a tier, notes, favorites, and a cover image to a catalog.
A charm is your own marker for search and organization. An alias is a display name that keeps the original filename. A tier is a rating such as S, A, or B.
A catalog treats files as one unit. Both a folder and a single file can be a catalog. Add several charms as your own markers to make it yours and easy to find.
Add the charms that match the way you will want to find things later.
