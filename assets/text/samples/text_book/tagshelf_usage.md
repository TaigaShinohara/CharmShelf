# CharmShelf 活用メモ

## 4つのまとめ方

1. 写真をフォトブックに
2. 音楽をアルバムに
3. イラストをイラスト集に
4. テキストを本に

カタログには、チャーム、別名、ティア、メモ、お気に入り、カバー画像を設定できます。
チャームは検索・整理に使う自分の目印、別名は元のファイル名を変えない表示用の名前、ティアはS・A・Bなどの評価です。
カタログは、ひとつのまとまりとして扱うファイルです。フォルダも単体ファイルもカタログにできます。自分の目印となるチャームをいくつもつけて、自分らしく、見つけやすく整理できます。
自分が後から探したい切り口を、少しずつ足していきましょう。
